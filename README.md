# Neon Relay — Arena Tag

Полноценная браузерная командная 3D-игра на Three.js без обязательных внешних игровых ассетов.

## Запуск

Самый простой вариант:

```bash
python -m http.server 8000
```

Затем открой:

http://localhost:8000

Запускать нужно из папки `arena_tag`.

Можно также разместить папку на любом обычном статическом хостинге.

## Управление на ПК

- WASD — движение
- Shift — ускорение
- Space — прыжок
- Ctrl — приседание
- мышь — обзор
- ЛКМ — лазерная метка
- R — перезарядка
- 1 / 2 / 3 — варианты мощности метки
- Esc — меню

## Управление на телефоне

- левый круг — движение
- свайп справа — обзор
- TAG — лазерная метка
- JUMP — прыжок
- CROUCH — приседание
- ↻ — перезарядка

Мобильный режим автоматически включается при сенсорном управлении.

## Реализовано

- Three.js WebGL
- Pointer Lock
- оригинальная 3D-карта
- две команды
- раунды и таймер
- очки
- кредиты
- магазин улучшений
- здоровье и энергия
- лазерные попадания через Raycaster
- hit effects и трассеры
- простые head/body hit zones
- боты с патрулированием, обнаружением игрока и атакой
- респавн
- столкновения
- прыжок и приседание
- HUD и kill/tag feed
- настройки громкости, чувствительности, FOV и качества
- localStorage
- Web Audio API
- процедурные модели окружения и персонажей

## Примечание

Игра сознательно использует безопасную механику лазертага вместо реалистичного оружия.
